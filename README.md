Telegram Message Forwarder Bot 
Простой и надежный бот на Python для автоматической пересылки сообщений из личного чата бота в определенную группу или канал.

  Особенности
Безопасность: Все конфиденциальные данные хранятся в файле .env и не попадают в код

Поддержка медиа: Бот пересылает текст, фотографии, видео, документы, голосовые сообщения и стикеры

Стабильность: Использование infinity_polling позволяет боту автоматически восстанавливать работу при кратковременных сбоях сети

  Установка и запуск
1. Подготовка
Убедитесь, что у вас установлен Python 3.8 или выше.

2. Клонирование и установка зависимостей
Создайте папку с проектом, перейдите в неё и установите библиотеки:

bash
pip install -r requirements.txt

3. Настройка конфигурации
Создайте в корневой директории файл .env и добавьте в него ваши данные:

env
BOT_TOKEN=ваш_токен_от_botfather
CHAT_ID=ID_вашего_чата/канала
Важно: Бот должен быть добавлен в целевую группу/канал как Администратор, иначе у него не будет прав на отправку сообщений.

4. Запуск
bash
python main.py

  Структура проекта
text
├── main.py           # основной код бота
├── .env              # файл с вашими секретными ключами (токен и ID чата)
├── requirements.txt  # список необходимых библиотек для установки
└── .gitignore        # список файлов, которые не должны попасть в публичный репозиторий
  Важное предупреждение о безопасности
Никогда не передавайте файл .env третьим лицам и не загружайте его в открытые репозитории на GitHub.
