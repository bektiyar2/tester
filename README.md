#  Telegram Message Forwarder

Простой и надежный Telegram-бот для автоматической пересылки сообщений из личного чата бота в конкретную группу или канал.

##  Возможности

- **Безопасность**: Использование переменных окружения через файл .env.
- **Поддержка медиа**: Пересылает текст, фото, видео, документы, голосовые сообщения и стикеры.
- **Стабильность**: Автоматическое переподключение при сбоях сети (infinity polling).
- **Легкость**: Минимум зависимостей и высокая скорость работы.

##  Установка и запуск

### 1. Подготовка
Убедитесь, что у вас установлен Python 3.8 или выше.

### 2. Установка зависимостей
Выполните команду в терминале:
pip install pyTelegramBotAPI python-dotenv

### 3. Настройка конфигурации
Создайте файл .env в папке с ботом и добавьте в него ваши данные:
BOT_TOKEN=ВАШ_ТОКЕН_ОТ_BOTFATHER
CHAT_ID=ID_ВАШЕГО_ЧАТА_ИЛИ_КАНАЛА

Важно: Бот должен быть добавлен в вашу группу и назначен администратором.

### 4. Запуск бота
python main.py

##  Структура проекта

- main.py — Основной программный код бота.
- .env — Файл с секретными настройками (токен и ID чата).
- requirements.txt — Список библиотек для установки.
- .gitignore — Инструкция для Git скрывать файл .env от интернета.

##  Деплой (Deployment)

1. Загрузите код в репозиторий GitHub (без файла .env).
2. На хостинге (например, Render) добавьте переменные окружения (Environment Variables) вручную.
3. Команда запуска: python main.py

##  Безопасность

Файл .env добавлен в .gitignore, чтобы ваши ключи доступа не попали в открытый доступ. Если вы случайно опубликовали свой токен — немедленно отзовите его через @BotFather.
